# Learning maps

These maps connect this repository to every lesson in the official [Agentic RAG](https://github.com/DataTalksClub/llm-zoomcamp/tree/main/01-agentic-rag) and [Vector Search](https://github.com/DataTalksClub/llm-zoomcamp/tree/main/02-vector-search) modules.

- [Week 1 — Agentic RAG](week1_agentic_rag.md)
- [Week 2 — Vector Search](week2_vector_search.md)

**Status meanings:** “Implemented” means the repository contains a corresponding example, not that homework or the entire lesson is complete. “Related” means a file illustrates part of the topic without implementing the full lesson. “Not represented” means no matching implementation was found. Conceptual wrap-ups do not require a program.

Commands assume the repository root and `uv sync`. Local embedding examples may download model weights; FAQ loading requires network access. API examples require configured credentials and may incur charges. Ingestion commands write persistent data; the SQLite script refuses to overwrite an existing database. See the [root README](../README.md) for configuration and PostgreSQL setup.
